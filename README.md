# Numb

A simple app to block user input on Windows without 'locking' the screen.

## Common scenarios

- Wipe down & clean keyboards and touchscreens without registering input.

- Keep public dashboards or slides visible without risk of tampering.

- Monitor active downloads, renders, or transfers at a distance.

- Let your toddler watch a movie AND safely bang on the keyboard

- Prevent pets from walking on the keyboard and disrupting active tasks.

- Stop children from accidentally muting, hanging up, or closing video chats with grandparents.

## Options

- Block all inputs
- Block keyboard input
- Block mouse input
- Block touch screen input
  - via screen overlay
  - via disabling touch device(s)
- Hotkey to toggle blocking
- User-lock device when unblocking
- Unblock with Ctrl+Alt+Del
- Blocking countdown
- Block when system is idle for specified period of time
- Block immediately on app startup
- Show information popup windows on blocking and unblocking
- Play sounds when blocking and unblocking
- Hide the tray icon when blocking
- Add app to Windows startup

## Why?

I used to use [KeyFreeze][1] but it doesn't support blocking touch screen input.
